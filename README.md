\# Calculadora em C



Primeiro projeto publicado no GitHub durante meus estudos de Análise e Desenvolvimento de Sistemas.



\## Funcionalidades



- Soma
  
- Subtração
  
- Multiplicação
  
- Divisão
  
- Menu interativo



\## Tecnologias



\- Linguagem C

\- Dev-C++



\## Objetivo



Praticar os fundamentos da programação utilizando a linguagem C, aplicando conceitos de lógica de programação, estruturas condicionais, laços de repetição e operações matemáticas.
