# Calculadora em C

Primeiro projeto publicado no GitHub durante meus estudos de Análise e Desenvolvimento de Sistemas.

## Funcionalidades

- Soma
- Subtração
- Multiplicação
- Divisão
- Menu interativo

## Tecnologias

- Linguagem C
- Dev-C++

## Objetivo

Praticar os fundamentos da programação utilizando a linguagem C, aplicando conceitos de lógica de programação, estruturas condicionais, laços de repetição e operações matemáticas.

## Observações

- A calculadora foi desenvolvida para trabalhar com números inteiros.
- Não há suporte para números decimais.
- Há validação das opções do menu e da divisão por zero.

## Conceitos Praticados

- Variáveis
- Entrada e saída de dados
- Estruturas condicionais (if/else)
- Estruturas de seleção (switch)
- Estruturas de repetição (while e do-while)
- Operações matemáticas
- Conversão de tipos (casting)
- Validação de entradas
